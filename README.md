# ربات آزمون آنلاین تلگرام

## امکانات نسخه اصلاح‌شده
- ثبت گروهی نام دانشجوها و ساخت کد اختصاصی یک‌بارمصرف برای هر نفر
- کد دانشجو فقط برای ورود اولیه است؛ پس از ورود مصرف می‌شود و مدیر می‌تواند دوباره فعالش کند.
- کد هر آزمون مشترک است؛ همه دانشجوها همان کد را وارد می‌کنند.
- هر دانشجو در هر آزمون فقط یک تلاش دارد؛ مدیر می‌تواند تلاش قبلی را بازنشانی کند تا امکان شرکت مجدد فراهم شود.
- ویرایش نام دانشجو و حذف کامل دانشجو به‌همراه پاسخ‌ها و نمره‌های مرتبط
- آزمون زمان‌بندی‌شده، سؤال تستی و تشریحی، تصحیح خودکار تستی و تصحیح دستی تشریحی
- ثبت پاسخ‌ها و بستن خودکار آزمون با پایان مدت مجاز

## شناسه تلگرام و نشست دانشجو
هیچ Telegram ID برای شناسایی یا ذخیره پرونده دانشجو استفاده نمی‌شود. جدول دانشجوها فقط شناسه داخلی دیتابیس، نام، کد اختصاصی و وضعیت مصرف کد را دارد. شناسه تلگرام فقط برای محدود کردن پنل مدیریت به `ADMIN_ID` استفاده می‌شود.

بعد از ورود موفق، شناسه داخلی دانشجو فقط در نشست موقت همان اجرای ربات نگهداری می‌شود. چون عمداً هیچ پیوند دائمی بین دانشجو و حساب تلگرام ذخیره نمی‌کنیم، اگر ربات Restart یا Deploy شود، نشست دانشجو از بین می‌رود. در این حالت مدیر باید کد دانشجو را دوباره فعال کند تا دانشجو وارد شود. این رفتار لازمه حذف کامل وابستگی شناسایی دانشجو به Telegram ID است.

تلگرام به ربات اطلاع نمی‌دهد که کاربر برنامه را بسته یا چت را ترک کرده است. بنابراین آزمون با دکمه «پایان آزمون» یا با رسیدن زمان مجاز به‌طور خودکار بسته می‌شود؛ بستن برنامه به‌تنهایی قابل تشخیص نیست.

## نصب
```bash
pip install -r requirements.txt
python bot.py
```

## متغیرهای محیطی
- `BOT_TOKEN`: توکن ربات از BotFather
- `ADMIN_ID`: شناسه عددی حساب مدیر (فقط برای حفاظت پنل مدیریت)
- `ADMIN_PASSWORD`: رمز قوی ورود مدیریت
- `DB_PATH`: مسیر فایل SQLite؛ باید روی فضای ذخیره‌سازی دائمی میزبان باشد.

## انتشار در GitHub و FeedHost
1. فایل‌های `bot.py`، `requirements.txt` و `README.md` را در ریشه مخزن GitHub قرار بده.
2. `.env.example` فقط نمونه است؛ توکن واقعی، شناسه مدیر و رمز را در GitHub ننویس.
3. در FeedHost یک سرویس Python/Worker بساز و مخزن GitHub را به آن متصل کن.
4. دستور نصب (Build/Install Command): `pip install -r requirements.txt`
5. دستور اجرا (Start/Run Command): `python bot.py`
6. در بخش Environment Variables این مقادیر را بساز: `BOT_TOKEN`، `ADMIN_ID`، `ADMIN_PASSWORD` و `DB_PATH`.
7. اگر FeedHost دیسک دائمی با مسیر `/data` ارائه می‌کند، مقدار `DB_PATH` را `/data/exam_bot.db` بگذار و مطمئن شو Persistent Disk به سرویس وصل شده است. اگر دیسک دائمی نداری، SQLite ممکن است با Deploy یا Restart پاک شود؛ قبل از استفاده واقعی باید دیتابیس دائمی فراهم شود.
8. Deploy کن و لاگ‌ها را ببین. پیام `Exam bot is running` نشانه شروع فرایند ربات است.

## زمان‌بندی
زمان‌های شروع و پایان با منطقه زمانی محلی سیستم میزبان تفسیر می‌شوند. منطقه زمانی FeedHost را با منطقه زمانی موردنظر آزمون‌ها هماهنگ کن. زمان‌ها را به شکل `YYYY-MM-DD HH:MM` وارد کن.

## ارتقا از نسخه قبلی
در شروع برنامه، اگر دیتابیس نسخه قبلی ستون `telegram_id` در جدول دانشجوها را داشته باشد، جدول دانشجوها بازسازی می‌شود تا آن ستون حذف شود. با این حال قبل از Deploy نسخه جدید، از دیتابیس قبلی نسخه پشتیبان بگیر.
